# Professional 2D Animation Skill

## Core Principles
- **Color Palettes**: High contrast, rich complementary tones (deep navy, radiant amber, teal accents, magenta highlights).
- **Geometric Precision**: Clean rounded shapes, consistent stroke widths (4-8px), no messy artifacts.
- **Micro-movements**: Secondary motion on loose accessories, constant gentle idle breathing, eye-darts, and blinking.
- **Transitions**: Geometric whip pans, shape morphs, match cuts, and color flood sweeps.
