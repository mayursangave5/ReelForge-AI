# Storyboarding & Visual Storytelling Skill

## Formula for High Retention
1. **First 2 Seconds Hook**: Start right in the middle of extreme action or an impossible question. High energy visual + dynamic sound hit.
2. **Shot Progression**: Never keep the camera static for more than 2-3 seconds. Alternate shot sizes: Extreme Wide -> Medium -> Macro Insert -> Close Up -> Dutch Angle.
3. **Escalation**: Demo 1 (small/personal) -> Demo 2 (city scale) -> Demo 3 (planetary scale).
4. **The Turn**: Ground the narrative in a real, calculated scientific fact with dramatic score drop.
5. **Ending**: Open question or cliffhanger that drives comment debate and subscriptions.
